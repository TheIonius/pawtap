# 🐾 pawtap • a gentle typing sanctuary

> A warm neutral aesthetic typing experience designed for soft focus, tactile delight, and playful typing joy.

---

## 🌸 Key Features

- **Pawtap Aesthetic Sanctuary**:
  - Curated color palettes: *Oat Milk & Honey*, *Matcha Milk*, *Strawberry Cream*, *Café Espresso*, *Lavender Mist*, *Linen & Stone (Japandi Neutro)*, *Brown Sugar Boba*, and *Midnight Lofi*.
  - Curated aesthetic typography: *Playpen Sans*, *Nunito*, *Lora*, *Fraunces*, *DM Mono*, and *Outfit*.
  - Customizable carets: Smooth Line, Cozy Underline, Soft Pill, Bouncing Droplet.

- **More Fun & Gamified**:
  - **Interactive Companion**: Animated vector companions (*Mochi the Cat*, *Steaming Latte*, *Sprouting Succulent*) that react live to your typing speed, streaks, and errors. Click them to pet!
  - **Difficulty Modifiers (osu!-style)**: Multi-selectable *Sudden Death* (instant fail on typo), *Hidden / Disappearing* (letters fade out), and *Flashlight* (narrow beam vision).
  - **Milestone Confetti & Victory Fanfare**: Warm pastel celebration bursts and melodic chime when setting a new Personal Best.
  - **Missed Words Drill**: One-click instant practice test targeting the specific keys or words you missed.

- **Web Audio Synthesizer (Zero External Audio Files)**:
  - Real-time synthesized mechanical switch audio:
    - *Creamy Thock* (deep, buttery lubed mechanical switch)
    - *Matcha Clack* (poppy, crisp linear clack)
    - *Bubble Pop* (playful soft popping water drops)
    - *Vintage Typewriter* (nostalgic mechanical strikes)
    - *Wood Tap* (organic marimba clicks)
  - **Cozy Ambient Audio**: Real-time synthesized *Gentle Rain* and *Lo-Fi Chill* (warm Rhodes jazz chords & vintage vinyl tape warble).

- **Typing Engine & Mechanics**:
  - Modes: **Time** (15s, 30s, 60s, 120s), **Words** (10, 25, 50, 100), **Quote** (Short, Medium, Long cozy literary passages), and **Zen** mode.
  - Toggles for Punctuation (`@`) and Numbers (`#`).
  - Toggle between **Cozy Vocabulary** (latte, blanket, ceramic, vanilla, drizzle...) and **Standard English 200**.
  - 3-line sliding word buffer with smooth caret interpolation.
  - Comprehensive results screen: WPM, Raw WPM, Accuracy, Consistency %, character breakdown, and interactive SVG speed trajectory graph.
  - Optional on-screen glowing visual keyboard.
  - LocalStorage persistence for themes, personal bests, and test counts.

---

## ⌨️ Shortcuts

- <kbd>Tab</kbd> — Instant restart test
- <kbd>Esc</kbd> — Open/close Cozy Sanctuary Customizer & Theme Picker
- <kbd>Ctrl</kbd> + <kbd>Backspace</kbd> — Delete whole word
- <kbd>Space</kbd> — Submit active word

## 🚀 Running the Project

```bash
cd pawtap
npm install
npm run dev
```

Open `http://localhost:5173` in your browser.
